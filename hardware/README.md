# Hardware evidence

The electrical design is documented under `electrical/`. This directory is reserved
for physical build evidence so that photographs cannot be confused with schematics or
planned layouts.

| Build stage | Published state |
|---|---|
| Modules with fitted headers | No photograph published |
| USB-powered breadboard | No photograph published |
| Perfboard assembly | Not assembled |
| Standalone power system | Not validated |
| Enclosure fit | Not validated |

Photographs should show the whole configuration and any connection that is important to
the recorded result. Each published image needs a nearby caption identifying the build
stage, date, power source, and whether that configuration produced a published log.

Review photographs for location metadata, addresses, labels, reflections, screens, and
unrelated background material before publication. See [`photos/README.md`](photos/README.md).
