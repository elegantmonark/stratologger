# Hardware photographs

No physical-build photographs are published at this revision.

Use descriptive filenames when evidence becomes available:

```text
modules-with-headers.jpeg
breadboard-overview.jpeg
breadboard-tft-closeup.jpeg
perfboard-component-side.jpeg
perfboard-solder-side.jpeg
enclosure-fit-check.jpeg
```

Before adding a photograph:

1. remove location metadata;
2. crop out personal documents, addresses, notifications, and unrelated screens;
3. confirm that the pictured wiring matches the accompanying netlist;
4. record the date, power source, firmware revision, and test result in the caption; and
5. avoid presenting an unpowered layout as a validated working configuration.
