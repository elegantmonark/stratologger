# Results

No physical test result is published at this revision.

The [telemetry log validation](log-validation/README.md) records a synthetic software
fault campaign and a checksum serialization fix. It is not a hardware capture.

Future results will be grouped by test type and will link to the matching hardware
revision, firmware revision, run metadata, raw log, validation output, and photographs.
A successful firmware build is reported in `docs/validation.md` as a software result;
it is not evidence of sensor, display, storage, power, or enclosure performance.
